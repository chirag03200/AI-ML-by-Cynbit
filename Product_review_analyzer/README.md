## 🛍️ Product Review Sentiment Analyzer

A **Streamlit web application** for analyzing sentiment in product reviews.  
Upload your dataset, and the app will classify each review as **Positive**, **Negative**, or **Neutral** using **NLTK’s VADER Sentiment Analyzer**.

---

## 📌 Features
- Upload `.txt` or `.csv` files containing product reviews.
- Automatic text preprocessing (lowercasing, punctuation removal, stopwords removal).
- Sentiment classification with VADER.
- Interactive charts showing sentiment distribution.
- Option to download processed results.
- Progress bar for large files.
