## 🖼 AI Image Caption Generator

An interactive **Streamlit web app** that generates descriptive captions for images using **Hugging Face image-to-text models**.  
Simply upload an image, and the AI will describe it for you. 🎯

---

## 🚀 Features
- **Upload an image** (JPG, JPEG, PNG)
- **AI-generated captions** using powerful Hugging Face models
- **Model selection** from the sidebar
- Adjustable **Max New Tokens**
- **Responsive layout** with image preview and generated text
- **CUDA GPU support** (if available) for faster inference
