# 🧠 Emotion Detection App

This is a simple and interactive **Emotion Detection App** built with **Streamlit** and a trained **machine learning model** using **scikit-learn**. It predicts the underlying emotion behind a sentence you enter — such as **joy**, **anger**, **sadness**, **fear**, **love**, or **surprise** — and displays prediction confidence with a probability chart.

## 📦 Features

- 📊 Probability distribution for all emotion classes
- 😄 Emoji display for easy interpretation
- ⚠️ Low-confidence warning for unreliable predictions
- 💡 Simple and clean UI with Streamlit
